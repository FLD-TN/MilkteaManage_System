# 🥤 Milktea Manage System (Hệ thống Quản lý Quán Trà Sữa)

Đây là Bài tập lớn môn học Lập trình Java, một ứng dụng desktop (Java Swing) được xây dựng nhằm hỗ trợ việc quản lý bán hàng tại quán trà sữa một cách chuyên nghiệp, hiện đại và hiệu quả.

## 🌟 Tính năng chính

- **Quản lý Sản phẩm (Menu):** Cho phép người quản trị thêm, sửa, xóa và tìm kiếm các loại đồ uống, topping dễ dàng.
- **Quản lý Bán hàng:** Hỗ trợ tạo đơn hàng mới, tính tiền nhanh chóng và xuất hóa đơn ra file PDF.
- **Quản lý Nhân viên:** Thêm, sửa, xóa thông tin nhân sự và phân quyền đăng nhập an toàn.
- **Thống kê Doanh thu:** Cung cấp biểu đồ trực quan giúp theo dõi tình hình kinh doanh theo ngày/tháng.
- **Chatbot Hỗ trợ:** Tích hợp tính năng hỏi đáp tự động để giải đáp các thông tin cơ bản.
